# DustIt for Raycast

See what's using disk space, clean up safely and check what's slowing your Mac down, right
from Raycast. It runs the [DustIt](https://github.com/iamolayemi/dustit) CLI, so install that first:

```bash
brew install iamolayemi/tap/dustit
```

Commands: **Disk Space**, **Clean Up Safely**, **Health Check**, **What Grew This Week**.

Develop locally with `npm install && npm run dev` (Raycast must be installed).
